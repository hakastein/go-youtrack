# Запрос уходит один раз, ошибка одна и несёт код

Факты — YouTrack 2026.1.13757.

- Транспорт: HTTP/1.1, без keep-alive, редиректов и прокси — иначе net/http сам повторяет запрос (GOAWAY HTTP/2,
  сломанное соединение). Таймауты: соединение и TLS 10 с, заголовки 60 с.
- Повторов нет. Исключение — `POST /issuesGetter/count`: на `-1` один повтор, второй `-1` даёт `total: null`.
- Ошибка — `*Error{Code, Message, Details, AfterWrite, Err}`, `errors.Is` по коду с `Err…`. `Warning` — то же без
  `AfterWrite`.

  | Код | Когда |
  |---|---|
  | `bad_usage` | вызов не отправить как написан (в том числе по метаданным проекта) |
  | `unknown_name` | имени нет там, где искали |
  | `missing_required` | запись оставляет пустыми обязательные поля |
  | `not_found` | `404` |
  | `denied` | `401`, `403`, проект без видимых полей |
  | `rejected` | `400` |
  | `upstream_failed` | `5xx` YouTrack, статус вне таблицы, сбой сети, поле сменилось между чтениями |
  | `upstream_invalid` | ответ не сходится с запросом или с записанным |
  | `write_uncertain` | запись ушла, исход неизвестен |

- Граница `write_uncertain` — `httptrace.WroteRequest`; оборванное тело под 2xx и 5xx — тоже. `Send` ставит её для
  записи через `API()`.
- `5xx` на запись с JSON-объектом со строковым `error` — `upstream_failed`, иначе ответил не YouTrack —
  `write_uncertain`. `MayHaveWritten()` — `write_uncertain` или `AfterWrite`.
- Слова сервера — дословно: `upstream_status`, `upstream_error`, `upstream_message`; `upstream_body` — если статус вне
  таблицы или тело не `{error, error_description}`.
- Не-JSON под не-5xx — `upstream_invalid`: лишний путь перед `api/` отвечает `200` и HTML.
- `request` пригоден к повтору: пароль маскирован, в query раскрыты только `,()$`. Внутренние id — только в `request`
  и `upstream_*`; исключение — созданные комментарий, вложение, запись времени и группы доступа тега.
- `NewClient` отвергает адрес не `http(s)`, без хоста, с query или фрагментом и токен пустой или с управляющим
  символом кроме TAB. Токена в сообщении нет.

## Отвергнуто

- Тип ошибки на класс исхода.
- Код из `error` сервера: там три словаря и ложные классы.
- Повтор на `5xx` и чтение обратно при неизвестном исходе.
