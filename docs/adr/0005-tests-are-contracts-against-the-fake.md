# Тесты — контракт против фейкового сервера

Тест проверяет только модуль и падает, только когда ломается поведение, названное в его имени.

## Решение

- **Слой один: контракт через экспорт против фейкового сервера.** Тест против дев-инстанса проверяет сам YouTrack и
  краснеет со сменой его версии, когда модуль ничего не нарушил, поэтому кассет и тестов против него нет. Факт о
  сервере, на котором стоит решение, записан в ADR с версией YouTrack; дев-инстанс ytrack остаётся для `make openapi`,
  ручных проверок и новых измерений.
- **Ошибку до сети проверяет вызов без HTTP** — сервер `fake.ServeNothing` роняет тест на любом запросе. Поведение,
  зависящее от ответа, проверяет вызов против `fake.Serve`, и ассерт стоит на документе целиком, на значении Go и на
  `Error` с кодом и деталями, а не на прозе.
- **Проза не сверяется — ни своя (`Message`, `Error()`), ни сервера**, потому что правка формулировки не меняет
  поведения. `NotEmpty` на прозе допустим. Поля ошибки, по которым ветвится потребитель, сверяются значением.
- **Ассерт стоит на значение**, а не на тип, длину или непустоту. Полный запрос (`fields=`, тело) сверяет только тест
  про этот запрос.
- **Каждую гарантию ADR, у которой есть код, держит хотя бы один тест**, и мутация, которая её снимает, роняет его:
  подмена класса в строке таблицы роняет тест записи по классу и ключу типа.
- **Таблица ошибок сверяет, каким правилом отвергнут кейс,** чтобы кейс, отвергнутый не тем правилом, не оставался
  зелёным. В теле теста нет логики: таблица — одна форма кейсов, кейсу со своей веткой нужен свой тест.
- **Фикстура названа по проверяемому свойству**, а не взята с дев-инстанса: `First`, `Second`, `Third` для порядка.
- **Тест — во внешнем пакете `youtrack_test`, на testify и таблицах.** Тестовых швов в проде нет.
- **Чужой код и YouTrack не проверяются:** net/http, `encoding/json`, сгенерированный клиент, поиск и права сервера.

## Фейковый сервер

- **Фейковый сервер, журнал запросов и сборщики ответов — публичный пакет `fake`,** потому что тесты потребителей
  ходят к нему же: TMS проверяет синхронизацию дерева из бандлов и запись поля, kraken — чтение полей.
- **Сервер один на тестовый пакет, и каждый тест получает свой префикс пути,** потому что адрес путь допускает, а
  клиент дописывает к нему `api/`. Префикс срезается до записи в журнал. На WSL каждый `bind()` стоит до секунды.
- **Журнал отдаёт запрос по номеру через `require`**, чтобы пропущенный запрос был провалом теста, а не паникой.
- **«Никто не слушает» — фиксированный адрес `fake.NobodyListens`**, порт 1, без поднятия и закрытия сокета.
- **Свой сервер поднимает только тест, которому общий не годится:** перестать слушать между двумя запросами
  (`fake.ServeAlone` и `StopListening`).
- **Фейк не знает YouTrack:** ответы даёт тест. Сборщики фикстур для метаданных, задач и бандлов живут в тестах, а не
  в `fake`, пока их не понадобится второму потребителю.
