# Тесты — контракт через экспорт против фейкового сервера

- Тесты — в пакете `youtrack_test`, на testify и таблицах; тестовых швов в проде нет. Кассет и тестов против живого
  YouTrack нет: факт сервера записывается в ADR с версией.
- Отказ до сети проверяется против `fake.ServeNothing`, поведение по ответу — против `fake.Serve`. Ассерт стоит на
  документе целиком, на значении Go и на `Error` с кодом и деталями; прозу проверяет только `NotEmpty`.
- Полный запрос (`fields=`, тело) сверяет только тест про этот запрос.
- Каждую гарантию ADR держит тест, который падает на мутации, снимающей её. Таблица отказов сверяет, каким правилом
  отвергнут кейс. В теле теста нет логики.
- Фикстуры названы по проверяемому свойству: `First`, `Second`, `Third`.
- Чужой код и сам YouTrack не тестируются.

## Фейковый сервер

- `fake` публичный. Сервер один на тестовый пакет, каждый тест получает свой префикс пути: на WSL каждый `bind()`
  стоит до секунды.
- Журнал отдаёт запрос по номеру через `require`. Адрес, где никто не слушает, — `NobodyListens`, порт 1.
- Отдельный сервер поднимает только тест, которому нужно перестать слушать между запросами (`ServeAlone`) или
  прочитать тело самому (`ServeUnread`).
- Ответы даёт тест. Исключение — сборщики разметки поиска `Searching`, `Markup` и `StyleRange`.
