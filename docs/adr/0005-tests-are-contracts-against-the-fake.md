# Тесты — контракт через экспорт против фейкового сервера

- Пакет `youtrack_test`, testify, таблицы. Швов в проде нет. Кассет и тестов против живого YouTrack нет: факт сервера —
  в ADR с версией.
- До сети — `fake.ServeNothing`; после — `fake.Serve`. Ассерт — на документ целиком, значение Go, `Error` с кодом и
  деталями. Проза не сверяется, только `NotEmpty`.
- Полный запрос (`fields=`, тело) сверяет только тест про запрос.
- Каждую гарантию ADR держит тест, который роняет её мутация. Таблица ошибок сверяет правило отказа. В теле теста нет
  логики.
- Фикстуры названы по свойству: `First`, `Second`, `Third`.
- Чужой код и YouTrack не тестируются.

## Фейковый сервер

- `fake` публичный: один `httptest.Server` на пакет, префикс пути на тест (на WSL `bind()` до секунды).
- Журнал отдаёт запрос по номеру через `require`. `NobodyListens` — порт 1.
- Свой сервер — только чтобы перестать слушать (`ServeAlone`) или читать тело самому (`ServeUnread`).
- Ответы даёт тест. Исключение — сборщики разметки поиска (`Searching`, `Markup`, `StyleRange`).
