# Документ — дерево под выражением вызывающего, отсутствующее имя проверяется по `$type`

Сервер под `200` молча опускает и опечатку, и имя, которого нет у типа объекта. Факты — YouTrack 2026.1.13757.

- Ответ и тело — деревья: отсутствующий ключ тела сервер не трогает.
- Выражение: пусто — поля по умолчанию, `+x` — они и `x`; «всё» нет (схема рекурсивна). По умолчанию — только то,
  что видит любой читатель.
- Синтаксис — до запроса, имена — после. Одно неверное имя проваливает операцию.
- Отсутствующий ключ K при `$type` T:

  | Случай | Результат |
  |---|---|
  | T из набора схем узла и объявляет K | `upstream_invalid` |
  | T из набора не объявляет K, другая схема набора объявляет | K опускается |
  | T не из набора, K объявлен в наборе | `upstream_invalid` |
  | K не объявляет ни одна схема набора | `unknown_name`; имя модуля — `upstream_invalid` |

  При обоих кодах — `upstream_invalid`. Лишнее поле ответа — не ошибка. Набор узла: в корне — схема ответа с потомками,
  ниже — объявленная у поля, при скаляре или объекте без схемы — иерархии, названные сервером. `unknown` несёт
  `nearest`: до пяти имён не дальше двух правок, иначе все имена набора; `missing` — `{field, type}`.
- Имена под `customFields` сверяются с каталогом полей инстанса (у токена без роли поля проекта пусты), один раз за
  вызов и только при названном имени. Совпадение — как у сервера.
- Каталог схем — `catalogue.gen.go` из `api/openapi.json` (`scripts/catalogue.go`).

## Документ

- Ключи — из `fields=`, в порядке запроса, по `CheckKey`. Ключ из данных — `DataPair`; два одинаковых — `upstream_invalid`.
- Многострочный текст — `description`, `text`, `content` записи целиком; в записи списка — строка.
- Время — ISO 8601 в UTC; длительность — `PT…H…M` из минут (`P1D` сервера — рабочий день). Подвыборка под
  длительностью — `bad_usage`.
- `url`, `thumbnailURL`, `avatarUrl`, `iconUrl` — абсолютные от адреса клиента без пароля; не путь — `upstream_invalid`.
  `base64Content` — `bad_usage`.
- Кастом-поля: названные — в порядке называния, целые — по `ordinal`. Поля, которого нет у задачи, нет в документе.
- Связи — фраза → задачи; пустые слоты опускаются, `null` среди слотов — `upstream_invalid`.
- Комментарии — выбором `Comments`, удалённые выбрасываются, порядок по `created`.
- Запись отвечает документом записанного и сверяется с ним: `mismatch`, `actual` — дословно.

## Активности

- `added`, `removed` — всегда список; схемы под ними — `ActivityItem` и `BundleElement`, чужое имя — `unknown_name`
  до запроса.
- `category` — id YouTrack, `field` — имя поля или непереведённая фраза (метку сводит `/api/issueLinkTypes`). Имя
  под ними — `bad_usage`.
- Без категорий уходят все; незнакомая — `unknown_name` до запроса (сервер отвечает на неё `[]`, без категорий — `400`).

## Отвергнуто

- Тела с тремя состояниями по всей спецификации.
- Отсутствующий ключ — всегда ошибка или всегда пропуск.
- Набор схем из присланных типов; подтипы в overlay.
