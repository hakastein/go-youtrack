# Тип поля — строка таблицы, класс берётся с задачи, запись сверяется по ключу значения

Факты — YouTrack 2026.1.13757.

- Тип поля — пара `valueType` и `isMultiValue`. Таблица ручная, строка на пару (класс записи, ключ значения, бандл).
  Пары вне двадцати строк — `upstream_invalid`, `FieldType.Known() == false`.

  | valueType | ключ значения | запись |
  |---|---|---|
  | enum, state, version, build, ownedField, group | `name` | `{"name": …}` |
  | user | `login` | `{"login": …}` |
  | period | `PT1H30M` из `minutes` | `{"minutes": N}` |
  | date | день ISO 8601 | полдень UTC, мс |
  | date and time | момент ISO 8601 в UTC | мс |
  | integer, float, string | скаляр | скаляр |
  | text | `text` | `{"text": …}` |

- `$type` поля в записи — как на задаче (`StateMachineIssueCustomField` под воркфлоу), иначе из таблицы. Обновление
  читает задачу, создание — проект.
- Имя поля разрешает модуль: `name`, затем `localizedName`, без регистра; в тело — канонический `name` (на другое
  сервер отвечает `500`). Нет поля — `unknown`, несколько — `ambiguous` с `candidates`.
- Имя значения разрешает сервер и правит регистр — сверка без регистра. Многозначное пишется целиком и сверяется
  набором. `Clear`: `null` однозначному, `[]` многозначному.
- До записи отвергаются: пустое значение, пробелы по краям и NEL, LS, PS в строке, период не `PT…H…M` или длиннее
  `2^31−1` минут, день не `ГГГГ-ММ-ДД`, момент без смещения или точнее мс, целое вне int32, число не по JSON — все
  разом одной ошибкой.
- Создание требует все обязательные поля, кроме заполняемых проектом и скрытых условием; обновление — только
  опустошаемые. Скрытое условием поле отвергается только при создании (сервер молча его выбрасывает). Условие —
  по телу записи, как у сервера.
- Пользователь — только логином: `me` и пользователь вне `aggregatedUsers` дают `400`.
- Ответ на запись сверяется с записанным: расхождение — `upstream_invalid` с `mismatch` и `AfterWrite`. `WriteFields`
  идёт путём `Create`/`Update`.
- Поля задачи — по `ordinal` привязки, при равенстве — по номеру привязки (у полей через REST `ordinal` 0). Поля проекта —
  по `ordinal`.
- Бандл — `values` у enum, state, version, build, ownedField; `Fields.Bundle` поля без бандла — `bad_usage`.
- Пустой список полей у `Fields` — `denied` с `project` и `permission`: без `jetbrains.jetpass.project-read` сервер
  отвечает `200` и `[]`. Запись пустой список отказом не считает.

## Запись времени

- Длительность — только `{"minutes": N}` (с `id` сервер даёт `400`); отрицательная и не из минут отвергается, ноль
  судит сервер.
- Без дня — без `date`, сервер ставит свой сегодняшний. День пишется полднем UTC, читается полуночью UTC.
- Обновление несёт только названные части; `null` в `type`, `text`, `value` атрибута опустошает.
- Тип работы — из `plugins.timeTrackingSettings.workItemTypes` проекта, по `id`; чужое имя — `unknown_name`.

## Что сервер хранит иначе

- Байт в байт: заголовок задачи с пробелами и TAB по краям, описание с хвостовыми пробелами, `---`, `~~~` и символом
  вне BMP, текст комментария, содержимое статьи и текст работы с CR, NEL, U+2028, BOM, заголовок статьи с TAB.
- Заголовок задачи: LF, CR, NEL, U+2028, U+2029 сервер заменяет — отвергается.
- Имя тега: края `\t\n\v\f\r`, U+001C–U+001F, Zs, Zl, Zp сервер режет — отвергается; LF внутри хранит.
- Имя файла: `\` и `"` (хранится хвост после обратной черты), CR, LF (хранятся `%0D`, `%0A`), символы ≤ U+0020 по
  краям — отвергаются. Подписанный `url` живёт до трёх дней.
- Логин с `/` уходит экранированным; `""`, `.`, `..` отвергаются.
- Связь задачи с собой — `200` без записи; отвергается.
- Запись во взятый назад комментарий сервер принимает молча — отвергается. Пустой комментарий: у задачи `400`, у статьи
  хранится — отвергается оба.

## Кэш метаданных

- Читают `Fields.Metadata`, `Show`, `Bundle`; пишут они же и `ReadMetadata`. Запись читает сервер, не кэш.
- Кэш подтверждает, не отказывает: расхождение (имя, форма id, тип вне таблицы, `404`, другая форма, поле сменилось) —
  промах и повторное чтение проекта. `denied`, `rejected`, сбой сети, `5xx` — не промах.
- `Bundle.Field.CanBeEmpty` — из ответа о поле.
- Каталог на пару адреса и токена, `0700`, файлы `0600`, токена нет. Пишется сразу после ответа; нечитаемый кэш — нет
  кэша.

## Отвергнуто

- Класс только из таблицы: поле под воркфлоу держится другим классом.
- Кэш в памяти.
- Повтор чтения на сменившемся поле.
