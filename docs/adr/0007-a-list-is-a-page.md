# Список — страница, её счёт проверяется

Факты — YouTrack 2026.1.13757.

- `Page{Skip, Limit}`: `Skip` 0…`2^31−1` (`0` не шлётся), `Limit` 0 — `DefaultLimit`, иначе 1…`2^31−1`, у активностей
  до `2^31−2` (берётся запись сверх лимита). За концом — пустая страница.
- `total` — весь результат, `truncated` — `total > skip + returned`; неполная страница считается без запроса.
  Неназванный счёт — `null`. У активностей `total: null`, обрезку доказывает запись сверх лимита.
- Счёт — тот же запрос с `fields=id&$top=-1` (кроме поиска задач). Так же целиком берутся поля проекта, теги и группы:
  без `$top` сервер обрывает теги на 42.
- Счёт меньше `skip + returned` — `upstream_failed`, записей больше лимита — `upstream_invalid`.
- Комментарии идут от старых к новым, активности (`reverse=true`) — от новых.
- Дочерние статьи — `Articles.Children`.
- Связи и поля проекта — без страницы.
