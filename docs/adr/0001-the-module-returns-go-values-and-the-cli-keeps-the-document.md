# Модуль отдаёт значения Go, а документ и словарь кодов остаются у CLI

YouTrack нужен трём потребителям: CLI для агентов (ytrack), сервису подготовки релизов (kraken) и системе
управления тестированием (TMS). Каждому нужны транспорт, знание о типах кастом-полей и проверка ответов, и только
одному — документ YAML и словарь кодов ошибок.

## Решение

- **В модуле — то, что нужно любому потребителю:** транспорт по адресу и постоянному токену, сгенерированный клиент
  ко всем операциям REST API, таблица типов кастом-полей, чтение задачи со значениями полей по имени, запись полей с
  проверкой ответа, бандлы полей проекта с кэшем метаданных, поиск пользователей и фейковый сервер для тестов.
- **У CLI остаётся слой «вызов → документ»:** дерево ответа под `--fields` вызывающего, каталог схем и проверка имён
  по `$type`, YAML, словарь кодов ошибок и коды возврата, поиск входа, команды, автодополнение и скрипты команд.
- **Модуль отдаёт типизированные значения:** `Issue`, `Field`, `Value`, `ProjectField`, `Bundle`, `User`. Значение
  кастом-поля — `Value{ID, Text}` по ключу значения его типа, потому что трём потребителям нужны имена, логины и
  внутренние id, а дерево под произвольным `fields=` нужно только CLI и приходит в `Issue.Tree`.
- **Модуль отдаёт ошибки Go, и тип ошибки называет, что делать дальше** ([ADR-0002](0002-the-transport-sends-once-and-an-error-is-a-type.md)).
  Словарь кодов ytrack ложится на типы модуля одной таблицей, поэтому ни один код в модуле не живёт.
- **Всё, чего типизированные функции не покрывают, доступно через `Client.API()`** — сгенерированный клиент поверх
  того же транспорта и токена.
- **Пакет `fake` публичный,** потому что тесты потребителей ходят к тому же фейковому серверу
  ([ADR-0005](0005-tests-are-contracts-against-the-fake.md)).
- **Импорты:** `youtrack → ytapi` только из адаптера `ytapi.go`; `fake` не импортирует ничего из модуля.

## Отвергнуто

- **Документ YAML и коды ошибок в модуле.** Сервисам они не нужны, а формат вывода CLI менялся бы вместе с модулем.
- **Значение кастом-поля как объединение типов Go.** Двадцать типов дали бы двадцать ветвей у каждого потребителя;
  ключ значения текстом — то, что печатает CLI, пишет TMS и читает kraken.
- **Поиск входа в модуле.** Правила про `YTRACK_URL`, `auth.json` и области принадлежат CLI и его пользователю.
- **Вложенный модуль в репозитории ytrack.** Путь импорта `github.com/hakastein/youtrack` и тег `v0.1.0` — у
  своего репозитория.
