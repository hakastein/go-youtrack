# go-youtrack

Go SDK для YouTrack. Здесь слова, которыми о нём говорят решения, комментарии и тесты. Термин называется так же,
как в коде, в API YouTrack или в net/http.

## Язык

### Клиент

**Клиент** (`Client`):
Один инстанс YouTrack и один постоянный токен к нему. Строится `NewClient` из адреса и токена и несёт сервисы.
_Avoid_: соединение, сессия

**Адрес инстанса** (`ParseAddress`):
`http(s)`-URL с хостом и, если нужно, путём — и ничего больше.
_Avoid_: base URL, endpoint

**Сервис** (`IssuesService`, `Client.Issues`):
Операции над одной сущностью YouTrack на клиенте: задачи, статьи, комментарии, вложения, связи, теги, записи
времени, активности, проекты, кастом-поля, пользователи.
_Avoid_: ресурс, эндпойнт, репозиторий

**Операция** (operation):
Метод сервиса. Документная называется по действию над сущностью (`Show`, `List`, `Create`, `Update`, `Delete`, `Add`,
`Remove`, `Children`) и отвечает документом; типизированная (`Issues.Get`, `Fields.Bundle`, `Users.Find`) — значением Go.
_Avoid_: вызов API, запрос, команда

**Адрес** (address):
Абсолютный `http`- или `https`-URL инстанса с хостом и путём, без query и фрагмента. К нему клиент дописывает `api/`.
_Avoid_: base URL, хост

**Транспорт** (transport):
`http.Client` клиента: HTTP/1.1, keep-alive выключен, редиректы не выполняются, прокси не читается. Ни один
запрос не отправляется дважды.
_Avoid_: HTTP-клиент, коннектор

**Запрос** (`request`):
Метод и URL с читаемым query, как вызывающий может отправить его снова. Стоит в деталях ошибки под `request`.
_Avoid_: эндпойнт, вызов

**Отправленный запрос** (sent request):
Запрос, байты которого ушли на сервер до сбоя (`httptrace.WroteRequest`). Отправленная запись без ответа —
`write_uncertain`.
_Avoid_: неопределённость, таймаут

**Сгенерированный клиент** (`ytapi.Client`):
Клиент ко всем операциям REST API, собранный oapi-codegen из спецификации. Отдаёт `*http.Response`. Внутри модуля его
видит только адаптер `ytapi.go`, наружу его даёт `Client.API`.
_Avoid_: низкоуровневый клиент, raw API

### Идентификаторы

**Читаемый id** (`idReadable`):
Идентификатор задачи вида `DEV-12` (код проекта, дефис, номер) или статьи вида `DEV-A-3`. Уходит в запрос как
написан; запись, которая сначала читает сущность, адресуется по `idReadable` из ответа.
_Avoid_: номер задачи, ключ

**Внутренний id** (`id`):
Идентификатор вида `7-12`, который YouTrack даёт любому объекту. Только он попадает в свой сегмент пути.
_Avoid_: entity id, id базы

**Код проекта** (project code, `shortName`):
Буква, затем буквы, цифры и подчёркивания: `DEV`.
_Avoid_: ключ проекта, имя проекта

**Владелец** (owner):
Задача или статья, к которой относятся комментарий, вложение или тег; называется читаемым id.
_Avoid_: родитель, контейнер

### Документ

**Документ** (document):
Ответ документной операции — узел-отображение, в котором каждое решение о данных уже принято; печать — только байты.
_Avoid_: результат, response, payload

**Узел** (`Node`):
Одно значение документа одного из видов (`Kind`): null, строка, число, bool, многострочный текст, список,
отображение ключей в порядке выражения полей.
_Avoid_: элемент, объект, value

**Многострочный текст** (`TextNode`):
Строковое свойство `description`, `text` или `content`, которое печатается блоком и доходит байт в байт.
_Avoid_: проза, длинная строка

**Ключ из данных** (`DataPair`, `FromData`):
Ключ отображения, взятый из данных сервера: имя кастом-поля, фраза связи. Остальные ключи — имена модуля по
грамматике `CheckKey`.
_Avoid_: динамический ключ

**Выражение полей** (fields expression):
`fields=` REST API в опциях операции: имена, у имени — список имён в скобках, кастом-поле задачи — имя под
`customFields`, в кавычках, если в нём есть что-то кроме букв и цифр любого алфавита, `_` и `$`. Его всегда пишет
вызывающий: пустое — `bad_usage`, своих полей по умолчанию у модуля нет.
_Avoid_: проекция, селектор, поля по умолчанию

**Каталог схем** (schema catalogue):
Схемы спецификации с родителями и свойствами, по которым имя выражения проверяется против `$type` ответа.
_Avoid_: модель данных, словарь типов

**Страница** (`Page`):
Окно списка: `Skip` записей пропущено, затем не больше `Limit`. Документ страницы несёт `total`, `returned` и
`truncated`.
_Avoid_: пагинация, курсор

**Свободный текст** (`free_text`):
Часть запроса поиска, которую YouTrack ищет словами, а не читает условием. О ней говорит предупреждение.
_Avoid_: полнотекстовый запрос

### Кастом-поля

**Кастом-поле** (custom field):
Поле задачи, заведённое в проекте: `State`, `Модуль системы`. На задаче — `Field`, на проекте — `ProjectField`.
_Avoid_: атрибут, свойство

**Каталог кастом-полей** (custom field catalogue):
Кастом-поля инстанса с именами и переводами, `GET /admin/customFieldSettings/customFields`. По нему разрешается
каждое имя под `customFields` в выражении полей задачи.
_Avoid_: словарь полей, справочник полей

**Поле проекта** (`ProjectField`):
Кастом-поле, как оно стоит на проекте: id привязки, имя, перевод имени, тип и `CanBeEmpty`.
_Avoid_: привязка, настройка поля

**Тип поля** (`FieldType`):
Пара `ValueType` и `Multi` — `fieldType.valueType` и `fieldType.isMultiValue` сервера. Строка таблицы типов задаёт по
ней класс, ключ значения и бандл. Пара вне двадцати строк таблицы — тип, которого модуль не знает (`Known`).
_Avoid_: вид поля, схема поля

**Класс** (`Class`):
`$type` кастом-поля задачи в теле записи: `SingleEnumIssueCustomField`, `StateIssueCustomField`. Берётся с задачи,
если поле на ней стоит, иначе из таблицы.
_Avoid_: тип записи, дискриминатор

**Ключ значения** (`ValueKey`, `Value.Text`):
Член значения, по которому оно читается и пишется: `name` у значения бандла и группы, `login` у пользователя, `text`
у текста, `minutes` у периода; у скаляра — сам скаляр. Текстом — как в `Value.Text` и `FieldWrite.Values`.
_Avoid_: отображаемое имя, представление

**Значение** (`Value`):
Одно значение кастом-поля на задаче: `Text` — ключ значения, `ID` — внутренний id у значения бандла, пользователя и
группы, `LocalizedName` — перевод значения бандла, который показывает интерфейс. Поле без значений держит пустой
список.
_Avoid_: элемент, опция

**Кодированное значение** (`Encoded`):
Ключ значения, переведённый `FieldType.Encode` в тело записи (`Body`) и ключ, под которым оно записано (`Key`).
_Avoid_: сериализованное значение

**Именованное значение** (named value):
Значение, которое сервер разрешает по имени и исправляет регистр: у бандлов, групп и пользователей. Сравнивается без
учёта регистра.
_Avoid_: справочное значение

**Бандл** (`Bundle`):
Значения, которые принимает поле проекта типов `enum`, `state`, `version`, `build` и `ownedField`
(`FieldType.HasBundle`): `bundle.values` с внутренним id, имена и признаком `Archived`. У остальных типов бандла нет.
_Avoid_: справочник, словарь значений

**Метаданные проекта** (`Metadata`):
Поля проекта одним `GET /admin/projects/{code}`: id привязки, `ordinal`, `canBeEmpty`, имя, перевод и тип.
`Fields.Metadata` отвечает из кэша (`FromCache`) или с сервера, `Fields.ReadMetadata` — только с сервера.
_Avoid_: схема проекта, конфигурация

**Кэш метаданных** (`WithMetadataCache`):
Метаданные проекта и каталог кастом-полей инстанса на диске между вызовами для одной пары адреса и токена. Кэш
подтверждает и не отказывает: расхождение с сервером — промах, и проект или каталог читается снова.
_Avoid_: локальная копия, снимок

### Запись

**Запись** (`FieldWrite`):
Одно кастом-поле задачи, которое заполняется значениями или опустошается `Clear`. Многозначное поле пишется целиком.
_Avoid_: патч, апдейт

**Проверка записи** (verify):
Сравнение записанного с ответом на запись: кастом-поля по ключу значения (именованные — без учёта регистра,
многозначные — как набор), остальные части как отправлены. Расхождение — `upstream_invalid` с `mismatch` после
записи.
_Avoid_: сверка, перечитывание

**Связь** (`Link`):
Слот `links` задачи: задачи на другом конце одного типа связи (`LinkType`) в одном направлении (`Direction`:
`OUTWARD`, `INWARD`, `BOTH`). Сервер присылает слот на каждый тип и направление, пустой — с `Issues: []`.
_Avoid_: ссылка, отношение

**Фраза связи** (`SourceToTarget`, `TargetToSource`):
Имя типа связи в одном направлении: `A "depends on" B`. Непереведённая фраза пустая.
_Avoid_: тип связи, направление связи

**Запись времени** (work item):
Затраченное на задачу время: длительность в целых минутах, день, тип работы, текст и атрибуты проекта.
_Avoid_: таймлог, трудозатраты

**Пользователь** (`User`):
Учётная запись инстанса: `id`, `login`, `fullName`, `email`, `banned`. `Users.Find` ищет по началу логина и полного
имени.
_Avoid_: аккаунт, участник

### Ошибки

**Ошибка** (`Error`):
Единственный вид ошибки модуля: код, сообщение, детали парами узла и признак `AfterWrite`.
_Avoid_: fault, отказ, exception

**Код** (`Code`):
Слово закрытого словаря, которое называет, что делать дальше: `bad_usage`, `unknown_name`, `missing_required`,
`not_found`, `denied`, `rejected`, `upstream_failed`, `upstream_invalid`, `write_uncertain`.
_Avoid_: тип ошибки, статус

**После записи** (`AfterWrite`, `MayHaveWritten`):
Ошибка, которая пришла, когда инстанс уже принял запись; с `write_uncertain` это ответ «инстанс мог измениться».
_Avoid_: частичный успех

**Слова сервера** (`upstream_*`):
Статус, `error`, `error_description` и тело ответа YouTrack в деталях ошибки дословно.
_Avoid_: причина, описание ошибки

**Предупреждение** (`Warning`):
То, что операция заметила и прошла мимо, той же формы, что ошибка, без `AfterWrite`.
_Avoid_: notice, лог

### Спецификация и тесты

**Спецификация** (`api/openapi.json`):
OpenAPI YouTrack, снятая `make openapi` с дев-инстанса YouTrack 2026.1.13757. Правится только overlay `api/overlay.yaml`.
_Avoid_: схема API, сваггер

**Фейковый сервер** (`fake.Server`):
Сервер для тестов: журналит каждый запрос и отвечает тем, что дал тест. Один на тестовый пакет, префикс пути на тест.
_Avoid_: мок, стаб
